# 实现说明

伴屿是本地 Node.js 服务与浏览器工作台的组合，面向 Windows 使用场景。此文档描述仓库现有代码结构，不代表所有外部服务场景均已实测。

| 模块 | 入口 | 职责 |
| --- | --- | --- |
| 本地管理服务 | `src/server.mjs` | 本机 HTTP 接口、管理令牌、页面和模块协调 |
| 业务存储 | `src/store.mjs` | 角色、会话、知识资料与人工待办 |
| 记忆 | `src/memory.mjs` | 原文索引、手动记忆、过滤与检索 |
| 模型 | `src/channel-models.mjs` | QQ / 微信分开设置来源和密钥 |
| QQ Agent | `src/qq-chat/` | 会话处理、工具、授权和任务状态 |
| 微信适配 | `src/adapters/weixin.mjs` | 私聊协议适配 |
| OneBot 传输 | `sharing/onebot-client.mjs` | 与单独安装的 QQ 接入组件通信 |
| 桌面运行 | `sharing/desk-runtime.mjs` | 后台守护和进程状态 |
| DSH 适配 | `vendor/dsh-client.js`、`src/dsh-*.mjs` | 本机模型调用与会话关联 |

## 数据边界

- 运行状态、聊天、记忆、密钥与登录配置位于本机 `data/`，不随仓库发布。
- 跨平台共享记忆是可选设置；开启后需理解相关片段可能出现在另一端的模型输入中。
- 工作台管理接口限制本机访问并校验管理令牌。
- 选择云端模型时，实际请求会向所配置模型服务发送相应内容；本地保存不意味着生成全过程离线。

## 第三方边界

工作台、QQ Agent 和 OneBot 适配为项目代码；QQ / DSH 客户端、LLBot / PMHQ 组件及外部授权服务独立取得。DSH 连接适配器包含按 MIT 许可使用的上游代码，详见根目录第三方说明。此仓库不分发上述客户端、原生组件、登录状态或任何访问令牌。
